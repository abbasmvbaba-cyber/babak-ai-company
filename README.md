# کمپانی هوش مصنوعی بابک — Babak AI Company 🚀

این مخزن، **محیط اصلی پروژه**ی کمپانی ماست.
هدف: یک داشبورد مدیریتی شرکتی که **بدون هیچ نصب و تنها با باز کردن آدرس** لود شود و مثل یک اپلیکیشن باز شود.

## ویژگی‌های هدف
- 🌐 بدون نصب — فقط با زدن آدرس وارد می‌شوی
- 📱 مثل اپلیکیشن (PWA) روی دسکتاپ و موبایل
- 🗂️ داشبورد شرکتی: کارمندان، دپارتمان‌ها، تسک‌ها، پروژه‌ها، گزارش‌ها
- 🤖 AI Command Center — دستیار هوشمند
- 🔌 اتصال به Supabase برای دیتابیس و Realtime

## فایل‌ها
| فایل | توضیح |
|------|-------|
| `index.html` | صفحه‌ی ورودی استاتیک، راست‌چین و بدون نیاز به نصب |
| `hr/index.html` | دایرکتوری گرافیکی ۷۲ پرسنل با جست‌وجو و فیلتر |
| `hr/data/employees.json` | دادهٔ ساختاریافته برای داشبورد یا ورود بعدی به Supabase |
| `hr/data/employees.csv` | خروجی قابل بررسی در Excel |
| `hr/data/employees-list.md` | فهرست متنی ۷۲ ردیفی با لینک پروندهٔ هر نفر |
| `hr/employees/BAC-xxxx/` | پروندهٔ اختصاصی، آواتار و اسناد نمونهٔ هر نفر |
| `hr/README.md` | توضیحات کامل بستهٔ HR و هشدار حریم خصوصی |
| `Agency-in-a-BOX-main.zip` | موتور متنی Agency-in-a-BOX برای مرحلهٔ اتصال بعدی |

## وضعیت فعلی
1. صفحه‌ی ورودی استاتیک ✅
2. بستهٔ HR نمونه برای ۷۲ نفر ✅
3. ساخت داشبورد کامل + تم نئونی در گام بعد
4. اتصال Supabase (دیتابیس، Auth و Realtime) در گام بعد
5. اضافه‌کردن PWA و AI Command Center در گام بعد
