# واحد منابع انسانی — کمپانی هوش مصنوعی بابک

این پوشه نخستین بستهٔ نمونه‌سازی HR برای اتصال به داشبورد شرکت است.

> **هشدار حریم خصوصی:** تمام رکوردهای فعلی ساختگی‌اند. کدهای ملی با قالب `IR-DEMO-...` عمداً غیرمعتبر هستند و فایل‌های `photo.svg` آواتار برداری‌اند، نه عکس افراد واقعی. هیچ کد ملی، تصویر، قرارداد یا مدرک واقعی را در رپوی عمومی GitHub قرار ندهید.

## خروجی فعلی

- **۷۲ رکورد پرسنلی** با شماره‌های `BAC-0001` تا `BAC-0072`
- **۵۸ خانم / ۱۴ آقا** — نزدیک‌ترین گرد کردن صحیح به نسبت ۸۰/۲۰ برای ۷۲ نفر
- **۱۴ نفر ۲۰ تا ۲۴ سال**
- **۳۶ نفر ۲۵ تا ۳۰ سال**
- **۲۲ نفر ۳۱ سال به بالا**
- **۴ رکورد دارای دکتری**
- همهٔ افراد در دادهٔ نمونه، ایرانی و دارای تاریخ‌ها به تقویم شمسی هستند.
- دوازده دپارتمان سازمانی، با نگاشت به هشت تیم Agency-in-a-BOX

## مسیرها

| مسیر | کاربرد |
|---|---|
| `index.html` | دایرکتوری گرافیکی، راست‌چین، جست‌وجو و فیلتر بر اساس نام، دپارتمان، جنسیت و سن |
| `data/employees.json` | منبع دادهٔ ساختاریافته برای داشبورد یا ورود بعدی به Supabase |
| `data/employees.csv` | خروجی مناسب برای بررسی در Excel یا ورود گروهی |
| `employees/BAC-xxxx/index.html` | پروندهٔ گرافیکی اختصاصی هر نفر |
| `employees/BAC-xxxx/profile.md` | پروندهٔ متنی HR با YAML front matter |
| `employees/BAC-xxxx/profile.json` | رکورد JSON اختصاصی |
| `employees/BAC-xxxx/photo.svg` | آواتار برداری ساختگی اختصاصی |
| `employees/BAC-xxxx/documents/` | استخدام، تحصیلات، جبران خدمات، خانواده و چک‌لیست مدارک |
| `scripts/generate_demo_hr.py` | بازتولید تمام ۷۲ رکورد و پوشه‌ها به صورت قطعی |
| `scripts/build_hr_directory.py` | ساخت دوبارهٔ دایرکتوری HTML از JSON |

## یادداشت مدارک

برای هر فرد، اسناد داخلی **غیرالزام‌آور** و رکوردهای نمایشی ساخته شده‌اند. مدارک هویتی، اصل مدرک تحصیلی، قرارداد نهایی امضاشده، بیمه و مالیات عمداً وضعیت «بارگذاری نشده» دارند؛ ساخت مدرک رسمی یا نگهداری PII واقعی در رپوی عمومی امن نیست.

## اجرای محلی

این بخش استاتیک است و نصب نمی‌خواهد. برای مشاهدهٔ محلی می‌توان فایل `index.html` را در مرورگر باز کرد یا از یک وب‌سرور ساده استفاده کرد:

```bash
python3 -m http.server 8080
```

سپس آدرس `http://localhost:8080/hr/` را باز کنید.

## وضعیت اتصال به موتور آژانس

فیلد `agency_team` در هر رکورد، دپارتمان HR را به تیم‌های Agency-in-a-BOX نگاشت می‌کند تا در مرحلهٔ بعد، گردش‌کارهای جذب، آموزش، ارزیابی و گزارش‌گیری روی همین داده‌ها اجرا شوند.
